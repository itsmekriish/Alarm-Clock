# Alarm-Clock
The Alarm Clock is a simple Python application built using Tkinter for the GUI and Pygame for audio playback. It allows users to set an alarm at a specific time, which will play a sound when the time is reached. Users can also stop the alarm manually. This project demonstrates basic threading, time handling, and GUI design in Python.


# Alarm Clock ⏰

## Description
The **Alarm Clock** is a Python-based application that allows users to set an alarm at a specific time. When the time matches the set alarm, an alert sound will be played. Users can also manually stop the alarm.

## Features
- Set an alarm for a specific hour, minute, and second.
- Plays an alarm sound (`sound.wav`) when the set time is reached.
- Stop the alarm manually.
- User-friendly graphical interface built with Tkinter.
- Uses threading to keep the application responsive.
